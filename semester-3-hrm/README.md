# 3학기 — 인적자원관리 (Human Resource Management, HRM)

> "사람을 어떻게 확보하고, 개발하고, 평가하고, 보상하고, 유지하는가?" 이론에서 실무 제도로 넘어가는 학기.

---

## 학습목표

- 나무위키 분류 기준 HRM의 6대 기능(직무관리 / 확보·개발관리 / 평가관리 / 보상관리 / 유지관리 / 방출관리)을 구분할 수 있다
- 채용, 성과평가, 보상 설계의 기본 원리와 함정을 설명할 수 있다
- "일반관리자(general manager) 관점"에서 인사제도를 전략적으로 사고할 수 있다

**선수지식:** 1~2학기 (조직행동론, 리더십·조직설계 기초)

### 왜 이 조합인가

- **Wharton `Managing Social and Human Capital`**은 Michael Useem·Peter Cappelli(둘 다 HR/조직 분야 최고 권위자)가 직무설계, 동기부여를 위한 보상체계 설계, 의사결정, 조직 아키텍처 변화를 "매니저의 관점"에서 가르칩니다. 이론이 아니라 바로 써먹는 실무 감각 위주입니다.
- **MIT `15.660 Strategic HR Management`**은 인사관리를 개별 기능(채용/평가/보상 등)이 아니라 **회사 전략과 연결된 하나의 시스템**으로 보도록 설계되었습니다 — 보상체계, 고성과 인사시스템(high-performance HR system), 교육훈련, 노사관계까지 전략적 관점에서 통합적으로 다룹니다. 이 레포에서 가장 "학문적으로 진지한" HRM 코스입니다.
- **KOCW 인적자원관리 강의들**은 채용관리·교육훈련·인력계획·임금관리·인사고과·노사관계관리·이직관리까지 한국 기업 맥락의 제도와 용어로 다시 정리해줍니다. 한국에서 취업/이직할 계획이 있다면 특히 유용합니다.

## 과제 / 산출물

1. **채용~평가~보상 설계 미니 프로젝트**: 가상의 직무(예: "백엔드 개발자 3년차") 하나를 정해서 직무기술서 → 채용 프로세스 → 평가 기준 → 보상 구조까지 일관되게 설계
2. **본인 회사(또는 인턴 경험) HR 제도 비평**: 실제 겪었던 인사제도(평가, 승진, 보상) 하나를 골라 이번 학기에 배운 이론으로 장단점 분석
3. `notes.md`에 정리해서 커밋
